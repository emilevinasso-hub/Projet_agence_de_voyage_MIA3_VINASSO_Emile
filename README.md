# Projet_agence_de_voyage_MIA3_VINASSO_Emile
Ce projet est une application console en C++ (compatible Dev-C++) qui informatise la gestion d’une agence de voyage de Cotonou. Elle permet d’enregistrer des passagers, d’ajouter et de rechercher des vols, puis de réserver un billet, de le payer et de l’annuler.
